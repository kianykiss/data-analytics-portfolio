# Data Analytics Portfolio
Repositório dedicado aos meus estudos e projetos práticos em **Python, SQL, Data Analytics, Engenharia de Dados e Data Quality**.

## Tecnologias

- **Python:** Pandas, NumPy, automação e análise de dados.
- **SQL:** Consultas, CTEs, Window Functions e otimização de queries.
- **Data Quality:** Validação, monitoramento e tratamento de inconsistências.
- **Analytics:** Análise exploratória, indicadores de desempenho e soluções para problemas de negócio.

## Estrutura

- `python/` — Scripts, exercícios e estudos em Python.
- `sql/` — Consultas SQL e técnicas de manipulação de dados.
- `projetos/` — Projetos aplicados com documentação e análises.

## Objetivo
Compartilhar conhecimentos técnicos, boas práticas e aplicações de dados na resolução de problemas reais de negócio.
